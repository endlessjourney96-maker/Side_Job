# 汎用リサーチキット

「何を知りたいか」を決めてから調べる、「調べた後に何を裏取りするか」を決めてから使う、の2点を徹底することで、リサーチの精度と速度を両立させるための型。

**共通ルール**：AIによるリサーチは「一次情報の要約・整理」までと割り切る。数字・料金・固有名詞・「いつの情報か」は必ず公式サイト・一次情報で裏取りする。AIの知識には鮮度の限界があるため、最新情報が必要な場合は検索ツールを使わせる、または「情報源を確認して」と明示的に頼む。

---

## ① 企業研究（面接・応募先向け）

**用途**：求人票だけでは分からない企業の実態・カルチャー・逆質問のネタを整理する

**プロンプト**
```
以下の企業について、転職面接に向けた企業研究をしてください。

【企業名・求人内容】
（貼る）

【調べてほしい観点】
・事業内容とここ1-2年の動き（新規事業、組織変更など。上場企業ならIR資料・決算説明資料も確認）
・募集背景（なぜ今このポジションを募集しているか、求人票から推測できる範囲で）
・カルチャー・働き方が分かる情報（社員インタビュー、口コミサイト等があれば）
・自分と企業の接点になりそうな情報（過去の取引実績、業界内での評判、共通の技術領域など）
・逆質問に使えそうな切り口（3〜5個）
・懸念点として面接前に確認しておいた方がよさそうなこと
```

**ポイント**：「懸念点」を必ず出させる。良い面ばかり整理すると、入社後のミスマッチに気づきにくくなる。

## ② 業界・トレンドリサーチ（note記事ネタ・市場感の把握向け）

**用途**：ジャンルの人気トピック、競合の傾向、最近の動きを把握する

**プロンプト**
```
以下のジャンル/キーワードについて調べてください。

【ジャンル/キーワード】
（貼る）

【出力形式】
・最近よく話題になっているトピック（3〜5個）
・競合・類似コンテンツの傾向（構成、切り口の分布）
・まだあまり扱われていなさそうな切り口（あれば）
・情報の鮮度（いつ時点の情報か）が分かるように明記
```

**ポイント**：note向けのジャンル調査で本格的にやりたい場合は `note-research` スキル（note記事チーム用）の方が専用設計。こちらは転職活動やツール選定など、note以外の場面での軽量リサーチに使う。

## ③ 情報の整理・ファクトチェック

**用途**：集めた情報がバラバラなときに、使える形に整理し直す

**プロンプト**
```
以下は調べた内容のメモです。整理してください。

【出力形式】
・確度が高い事実（複数ソースで確認できる/公式情報）
・確度が低い・要確認の情報（推測、単一ソース、古い可能性）
・結論として言えそうなこと

【調べたメモ】
（貼る）
```

**ポイント**：「確度が低い情報」を隠さずに分けて出させることで、そのまま鵜呑みにするリスクを減らす。
