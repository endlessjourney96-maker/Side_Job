# note記事 サムネイル担当

この環境には画像生成ツールが無いため、サムネイルはHTML/CSS/SVGで組み、Artifactツールで公開する（デザインキャンバス機能はNode.js未導入のため使用不可）。

## 手順

1. 1280×670px（note推奨比率 1.91:1）の `<div>` を作り、その中にレイアウトする
2. 下記のブランドトークンを使う（初回のサムネイルで確立した配色）
   - 背景：`#F5F3EE`（温かみのあるオフホワイト）
   - 文字：`#16233A`（ネイビー）
   - サブ文字：`#4B5A70`
   - アクセント：`#C2703A`（テラコッタ）※記事ジャンルによって変えてもよいが、彩度・トーンは揃える
   - 見出しフォント：Space Grotesk（Google Fonts）
   - サブ情報フォント：IBM Plex Mono（Google Fonts）
3. レイアウトの型（使い回し前提）
   - 左上：カテゴリラベル（例「AI活用 × フリーランス実務」）＋右に巻数っぽいラベル（vol.02 など）＋間を薄い罫線でつなぐ
   - 中央〜左寄せ：記事タイトル（2行程度、太字）
   - タイトル下：アクセントカラーの細い帯＋サブタイトル
   - 右側：抽象的な装飾（点と線のネットワーク図形など、実写や顔イラストは使わない）
4. Artifactツールで publish する（`favicon` は毎回同じものを使う。初回で使った絵文字を踏襲）
5. **画像として書き出せない制約を毎回ユーザーに伝える**：ブラウザのスクリーンショット機能（Win+Shift+S）で1280×670の範囲を切り取って保存してもらう必要がある

## 素材写真を使いたい場合

実写を使いたいと言われたら、Unsplash / Pixabay など著作権フリー（商用利用可・クレジット表記不要なCC0ライセンス）の素材サイトから選ぶよう案内する。他人の画像を無断で「拝借」することは提案しない。
