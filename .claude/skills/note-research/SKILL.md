# note記事チーム：リサーチ担当

新しい記事を書く前に、毎回このステップを踏む。目的は「同じような記事が既に大量にあるテーマを避け、差別化できる切り口を見つけること」。ここでの成果物は、次工程の企画マン（[[note-planner]]）がそのまま使えるインプット。

## やること

1. 対象ジャンル/キーワードで以下を検索する
   - `note {ジャンル} 売れる 記事`
   - `note {ジャンル} 2026`（その時点の年、トレンドキーワード把握用）
   - `{ジャンル} AI活用`（AI活用ジャンルとの掛け算余地を探る）
   - `note {ジャンル} 人気`（人気記事の傾向）
2. 見つかった競合記事（3〜5本程度）について、確認できる範囲で以下を分析する
   - **構成**：見出しの立て方、目次の有無、導入〜結論の流れ
   - **価格帯**：無料/有料の別、有料なら価格（300円/500円/1,000円超など）
   - **反応の目安**：スキ数、コメント数、レビュー数など公開されている数字（note記事ページに表示されているものだけを見る。非公開の売上数などは推測しない）
   - **タイトルの型**：数字系、体験談系、Before/After系など
3. 検索結果から拾うのは要点のみ（全文は読み込まない）
   - よく使われているタイトルの型
   - 価格帯の相場
   - 既に飽和している切り口（避けるべき）
   - まだ手薄な切り口（狙い目）

## 出力フォーマット

```
■ジャンル：（対象）
■トレンドキーワード：（1〜2行）
■競合分析（3〜5本）：
  ・タイトル／価格／スキ数の目安／構成の特徴（記事ごとに1行）
■よくあるタイトルの型：（1〜2行）
■価格帯の目安：（1行）
■狙い目の切り口：（1〜2行、理由つき）
```

このフォーマットのまま、企画マン（[[note-planner]]）に渡す。

## 注意点

- リサーチに時間をかけすぎない（5〜10分程度で十分）。この人の記事の強みは一次情報（実体験）なので、検索結果はあくまで「型」と「相場観」を知るための参考にとどめる
- 検索結果をそのままコピーしない。二次情報の丸写しは note の方針的にも読者価値的にも避ける
- スキ数などの数字は「だいたいこのくらい」という目安であり、断定・誇張しない
