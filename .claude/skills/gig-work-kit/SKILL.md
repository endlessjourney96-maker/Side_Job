# クラウドソーシング案件対応キット

2026-09-12、「スキル作りながら副業収入を作る」流れの一環として、ココナラ・クラウドワークスでの受託作業を支援する目的で作成。[[spot-consulting-kit]]が「単価の高いスポット相談」を扱うのに対し、こちらは「テキストベースで完結する、比較的単価は低いが即金性の高い受託案件」を扱う。両方とも同じ[[project_side_income_5man_goal]]（月5万円）の一部として、`spot-consulting/収益トラッカー.md`の「経路」列にまとめて記録する。

## できないこと（必ず伝える）

- プラットフォームへのログイン・案件閲覧・応募・メッセージ送信・報酬受取は代行しない。すべて対外的なコミットメントが発生する行為であり、必ずユーザー本人が行う
- クライアントとのやり取りは「下書き作成→ユーザー確認→送信」の順を必ず守る（`knowledge/lessons-learned.md`のメール対応原則と同じ）

## ① 案件の適性判定

募集文を貼ってもらったら、以下を判定する：
1. **自動化でどこまで完結できるか**（テキストin/text outで完結する案件は◎、対面・訪問・専門ソフト操作が必須な案件は✕）
2. **単価と工数の見合い**（相場観：資料作成1ページ4,000円〜、議事録・事務代行系は時給換算1,000〜1,500円目安、ライティング系1,500〜2,500円目安）
3. **既存スキルとの相性**（[[pm-ai-kit]]の議事録整理、[[research-kit]]のリサーチ、[[job-hunt-kit]]の添削、資料構成など、そのまま使える型があるか）
4. 判定結果を「◎やるべき／△条件次第／✕見送り」で一言コメント付きで返す

## ② 提案文の作成

適性◎の案件について、以下を含む提案文ドラフトを作る：
- 案件内容の理解を一言で示す（丸写しにしない）
- 対応できる範囲・進め方
- 納期の目安
- 実績・強みを一言（ハンドルネーム運用の場合、経歴の詳細は出さず「〇〇分野の整理・言語化を得意としています」程度に留める。[[feedback_handle_name_anonymity]]の方針に従う）

**送信はユーザーが行う。**

## ③ 受注後の納品物作成

案件のジャンルに応じて、既存スキルを呼び出す：
- 議事録・要約系 → [[pm-ai-kit]]
- リサーチ・調査系 → [[research-kit]]
- 添削・文章系 → [[job-hunt-kit]]の型を流用、または直接執筆
- 資料構成・パワポ系 → 見出し構成→内容→デザイン指示、の順で作る

納品前に、必ずユーザーに最終確認してもらってからアップロードする。

## ④ 実績トラッキング

`spot-consulting/収益トラッカー.md`に、経路を「ココナラ」「クラウドワークス」等として追記する。

## ⑤ ノウハウのスキル化・商品化

案件対応を重ねる中で「この種類の案件は毎回同じ手順で速く作れる」というパターンが見つかったら、[[skill-scout]]のbacklogに候補として記録する。将来的には「このやり方自体」をnote記事・テンプレート販売・spot-consultingの商品として売ることも視野に入れる（例：「AIで議事録整理を代行する自分のワークフロー、全部見せます」という有料記事化）。

## 心構え

- 今すでに note（スポット相談導線）・アフィリエイト・転職活動、と並行しているので、これを4本目として全力投入するのではなく、**まず1案件を試験的に受注してみて、実際の時間対効果を検証してから広げる**のが良い。分散させすぎない
