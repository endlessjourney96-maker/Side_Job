# 企業分析フル版シート（ドラフト）

`job-hunt-kit`②（企業別面接対策資料）が想定問答の差分カスタマイズなのに対し、こちらは「面接が確定した」企業に絞って、より深く・広く準備するためのもの。使い分け：応募段階では②、一次面接以降の重要な面接ではこちらを追加で作る。

---

## 固定セクション構成（6セクション）

1. **企業の基礎情報**：正式名称・設立・資本金・従業員数・売上高・事業内容など
2. **対象部署・ポジション情報**：求人タイトル・想定年収・選考フロー・面接日時
3. **最近のDXに関するニュース**：直近の具体的施策・報道
4. **私とこの企業のつながり**（最重要セクション）：なぜ私か／なぜこの企業か
5. **面接で推すべき話・アドバイス**：推すべき自己PR・意識すべきポイント・逆質問アイデア
6. **DX案件のボトルネック予想と、私のアプローチ**：想定されるボトルネックのパターンに当てはめ、自分の経験でどう解決に貢献できるかを言語化する

**4番が肝**：「企業研究」で終わらせず、その企業の直近の課題・事業内容と、本人の具体的な過去エピソード（過去の実務経験、海外案件でのチーム再編経験など）を明示的に結びつけて、「なぜ自分でないとダメか」を論理的に語れる形にする。

**6番の狙い**：DX推進が失敗する典型パターンに当てはめて仮説を立て、面接で「御社の課題はここでは」と自分から仮説をぶつけられるようにする。

### DXが「うまくいかない」7パターン（ボトルネック仮説フレームワーク）

① そもそもPJが前に進まない（現場の協力が得られない／部門間調整／経営と現場で目的がズレる／「DXやれ」だけで中身が決まっていない）
② 作ったが、狙った成果が出ない（想定より効率化できない／AIの精度不足／利用率が上がらない／PoCは良かったが本番で使われない）
③ 作るところまでは成功したが、定着しない（システムは完成したが現場が従来のExcel・紙に戻る＝「使われないDX」）
④ 既存システム・データが足かせになる（古い基幹システムとの連携／データがバラバラ／データそのものが汚い）
⑤ DX人材・推進体制が足りない（引っ張れる人がいない／IT部門だけで進めてしまう／現場とITを翻訳できる人がいない）
⑥ 費用対効果が説明できない（「儲かったの？」に答えられず次の予算が取れない）
⑦ PoCから本番に進めない（試すところまではできるが全社展開・業務組み込みで止まる）

**使い方の設計思想**：技術的な②（想定より成果が出ない）よりも、③（作れたのに人・組織・業務が変わらず定着しない）の方が本質的な難所であることが多い。逆質問でも「技術面より、現場定着や部門調整の方が大きいのでは」と③④⑤を先に匂わせる聞き方をすると刺さりやすい。

**運用フロー**：企業の求人票・事業内容からどのパターンに該当しそうかを推測し、逆質問にそのまま使う（「御社の場合、DXが進みにくいとしたら③④あたりが要因ではと想像しているのですが、実際はいかがですか」のような聞き方）。`dx-consulting-framework`の6視点診断（特に「定着」「組織」）と組み合わせると、仮説の精度が上がる。

**プロンプト**
```
以下の情報から、面接に向けた企業分析フル版シートを作ってください。

【企業の基礎情報・求人内容】
（貼る）

【最近のDX関連ニュース（調べた範囲でよい。research-kitで先に調査してもよい）】
（貼る）

【自分の経歴・強み（knowledge/user-profile.md参照）】
（貼る）

【出力形式】
1. 企業の基礎情報
2. 対象部署・ポジション情報
3. 最近のDXに関するニュース
4. 私とこの企業のつながり（なぜ私か／なぜこの企業か。過去の具体的エピソードと企業の課題を明示的に結びつける）
5. 面接で推すべき話・アドバイス（自己PR・意識すべきポイント・逆質問アイデア）
6. DX案件のボトルネック予想と、私のアプローチ（想定されるボトルネックと、自分の経験でどう貢献できるか）
```

**ポイント**：4番と6番は「調べて終わり」にせず、必ず本人の実体験（`knowledge/user-profile.md`のキャリアの核、`job-hunt-kit`①の実績エピソード）と接続させる。企業研究だけなら`research-kit`で十分だが、こちらは「自分ごと化」までがゴール。

## 本採用に向けた確認事項（ユーザー確認待ち）

- どの面接から「フル版」を作るか（全企業だと工数が重いので、一次面接通過後・最終面接前などの基準を決めておくとよさそう）
- `research-kit`①企業研究との役割分担（③は`research-kit`に任せ、こちらは④⑥の「自分ごと化」に専念する形が良さそう）
- 各社への当てはめ（進行中の選考状況）は汎用スキル側ではなく `knowledge/user-profile.md` に記録済み
