# 転職活動 日次プランナー（ドラフト）

Calendar・Gmail・応募企業一覧の3つを横断して、「今日何をすべきか」を1枚にまとめる。`job-hunt-kit`が個別作業の下ごしらえなのに対し、こちらは「今日1日の優先順位づけ」を担当する。

**前提**：Gmail/Calendar MCP連携が使える環境で動く（このプロジェクトでは`job_hunt_tracker`基盤を流用できる想定）。

**共通ルール**：ここで作るのはあくまで「一覧・整理」まで。メール返信の送信、日程の確定などユーザーの意思決定が必要な行為は絶対に自動実行しない（`job-hunt-kit`の「取得→判定→返信案作成→ユーザー確認→送信」の原則を踏襲）。

---

## ① 今日のタスク一覧生成

**用途**：朝いちで「今日の転職活動、何から手をつけるか」を把握する

**やり方**
1. Google Calendarで今日の面接・企業とのアポの有無を確認する
2. Gmailで直近（前回チェックから今まで、目安24時間）の採用関連メールを確認し、優先度判定する（`job-hunt-kit`④の優先度ルールを使用：面接・選考結果・日程調整・提出物・内定・オファー・エージェント重要連絡＝優先、広告・メルマガ等＝無視）
3. 応募企業一覧.xlsxを確認し、「返信待ち」「書類提出期限が近い」等のステータスを拾う
4. 以下の6区分に振り分けて出力する：
   - 今日の面接（時間・企業名・準備状況）
   - 事前準備（面接がある場合、`job-hunt-kit`①②の資料が揃っているか確認）
   - 提出物（期限が近いもの）
   - 返信（返信すべきメール一覧、下書きは作らずリストアップのみ）
   - 企業研究（次の面接に向けて`research-kit`で調べておくべき企業）
   - 面接後フォロー（前回面接の振り返り・お礼連絡が必要か）
5. タスク量が多い日は「必須／できれば／後回し」の3段階に分類する

**プロンプト**
```
以下の情報から、今日の転職活動タスクを整理してください。

【今日のカレンダー予定】
（貼る）

【直近の採用関連メール（要約でよい）】
（貼る）

【応募企業一覧の現状（進行中・返信待ち・期限が近いものなど）】
（貼る）

【出力形式】
・今日の面接（あれば）
・事前準備
・提出物
・返信（下書き作成はせず、対応が必要なメールをリストアップするだけ）
・企業研究
・面接後フォロー
最後に、タスクが多い場合は「必須／できれば／後回し」に分類してください。
```

**ポイント**：メールの返信案は`job-hunt-kit`③のテンプレートに任せ、ここでは「何をすべきか」の一覧化に専念する。役割を分けることで、プロンプトがシンプルに保てる。
