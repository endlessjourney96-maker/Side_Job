# 企業別スコアリングシート（ドラフト）

「自分に合うか」と「一般的に良い会社か」を混ぜないよう、評価を2枚のシートに分ける。`job-hunt-kit`が個別企業への対策なら、こちらは複数の応募先を横並びで比較・優先順位づけするためのもの。

**設計思想**：主観（本人適性）と客観（世間的な評価）を1つの表に混ぜると、「良い会社そうだから」で本人の軸がブレる。分けることで、両方を見ながらも本人の判断軸を主にできる。

---

## ① 企業別_AI独自総合評価（本人適性軸）

**用途**：自分の価値観・強み・キャリア軸に照らして、この企業が自分にどれだけ合うかを評価する

**評価項目（0.1〜10.0点、11項目）**
- 働きやすさ
- 企業理念マッチ
- 仕事内容の魅力
- 裁量権・意思決定関与
- キャリアパス成長
- 人柄・カルチャー
- 事業成長性・将来性
- DX推進の本気度
- AIエージェント親和性
- 年収・待遇
- 企業の安定性

各項目に「なぜその点数か」を一言メモする欄を設け、全項目の平均を「総合評価」列として自動計算し、降順ソートする。

**プロンプト**
```
以下の企業について、本人適性軸で11項目のスコアをつけてください（0.1〜10.0点）。

【評価する企業の情報】
（求人内容、企業研究メモなどを貼る）

【本人の価値観・キャリア軸】
（knowledge/user-profile.md の「転職活動の軸」「キャリアの核」を貼る）

【評価項目】
働きやすさ／企業理念マッチ／仕事内容の魅力／裁量権・意思決定関与／
キャリアパス成長／人柄・カルチャー／事業成長性・将来性／DX推進の本気度／
AIエージェント親和性／年収・待遇／企業の安定性

各項目に点数＋「なぜその点数か」を一言添えてください。最後に平均点も出してください。
```

## ② 企業別_一般評価ランキング（客観軸）

**用途**：世間的・客観的に見てどう評価される企業かを整理する

**評価項目（0.1〜10.0点、6項目）**
- 人気企業度（知名度）
- 働きやすさ
- 離職率の低さ（定着率）
- 給与水準
- 安定性・財務健全性
- 社会的評価・評判

**情報源**：有価証券報告書、OpenWork等の口コミサイト、求人票、報道などから独自に数値化する。

**注意（必ず明記する）**：公式ランキングの転載ではなく独自集計である旨を、シート内に注記として必ず入れる（「公式っぽく見えすぎない」ための予防線）。

**プロンプト**
```
以下の企業について、客観軸で6項目のスコアをつけてください（0.1〜10.0点）。
情報源は有価証券報告書・口コミサイト・求人票・報道などとし、
「独自集計であり公式ランキングではない」旨を明記してください。

【企業名・調べられる範囲の情報】
（貼る）

【評価項目】
人気企業度(知名度)／働きやすさ／離職率の低さ(定着率)／給与水準／
安定性・財務健全性／社会的評価・評判

各項目に点数＋根拠を一言添えてください。最後に平均点も出してください。
```

**ポイント**：①と②を混ぜない。①が下がっても②が高いことはあり得るし、その逆もある。両方を並べて見比べることで「客観的には良いが自分には合わなそう」といった判断ができる。
