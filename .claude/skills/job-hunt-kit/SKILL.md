# 転職活動 AI活用キット

`02_面接対策`フォルダでの実際の作業（2026年9月分）から抽出した型。面接対策資料は使い回せる「核」の部分と、企業ごとにカスタマイズする部分を分けて作るのがコツ。

**共通ルール**：AIに任せるのは下書きまで。数字・固有名詞・「言っていないこと」が混ざっていないかは必ず自分で確認する。特に転職理由・退職理由は事実と語り口を意識的にコントロールしたい部分なので、AI任せにしすぎない。

**ファイル命名規則**：`YYYY-MM-DD_企業名_面接対策資料.docx`（`02_面接対策`フォルダ内）。使い回す汎用パーツ（想定問答まとめ等）は企業名を入れずに保存する。

## ① 面接想定問答まとめ（汎用の「核」を作る）

**用途**：どの企業にも使い回せる、自己紹介〜逆質問までの回答の核を一度作っておく

**構成要素（14項目フル版）**
1. 自己紹介（経歴の概要だけに絞る。詳細は自己PR・実績エピソードに譲る）
2. 転職理由（ダイジェスト版＋深掘り用の時代ごとの版。各段階の冒頭に「前段階で得た気づき」を一言添えて一本のストーリーにする）
3. 志望動機（汎用版。企業ごとに②でカスタマイズする前提。生成ルールは②参照）
4. 自己PR（強みは1〜2個に絞り、詳細はエピソードに譲る）
5. 成功実績（STAR型で1〜2個）
6. 失敗経験（何を学び、その後どう行動を変えたかまでセットで用意する。失敗を隠さず、学習能力の証拠として使う）
7. STAR形式エピソード（**状況・課題・行動・結果**。「コミュニケーション不足」のような抽象語ではなく「AとBが同じ単位で会議したことがなかった」のような具体事実を入れる）
8. 企業との接点（過去の取引・知人・登壇記事など、企業ごとに個別に用意する項目）
9. 想定質問（求人票・企業研究から予測される、その企業特有の質問）
10. 逆質問（汎用的に使える切り口を5つ程度）
11. 年収（希望レンジ。「年収だけで判断しない」という総合判断のスタンスとセットで用意する）
12. 入社可能時期
13. 志望順位（聞かれた時にどう答えるか。正直さと駆け引きのバランスを事前に決めておく）
14. 面接後確認事項（次の選考ステップ、確認したいことのメモ）

項目3・5・6・7・8・9・11・13は企業ごとに差分が出やすい。1・2・4・10・12は汎用の「核」としてほぼ使い回せる。

**面接回答の原則**
- 回答は暗記した文章にしすぎない。キーワードとストーリーだけを用意し、普段仕事をしている時の自然な自分に近い状態で話す
- 面接は合否判定の場だけでなく、「相手企業の課題を理解する」「自分ならどう改善するか考える」「会話から双方に何か気づきを残す」という、コンサルティング的な場として使う

**プロンプト**
```
これから転職面接の想定問答をまとめます。以下の職歴・強み・実績をもとに、
自己紹介／転職理由（ダイジェスト版と時代ごとの深掘り版）／志望動機（汎用版）／
自己PR／成功実績／失敗経験（学びと行動変化つき）／STAR形式エピソード／
逆質問(5つ)／年収の考え方／入社可能時期
を作成してください。

【職歴・強み・実績のメモ】
（ここに経歴や実績を箇条書きで貼る）

【意識してほしいこと】
・転職理由は前向きな「気づき」を核にし、不満ベースの言い方は避ける
・各項目の後に「こだわりポイント」として、なぜその構成・言い回しにしたかも一言添える
・エピソードは抽象語を避け、具体的な事実を入れる
・回答は一字一句の台本ではなく、キーワードとストーリーの骨組みとして作る
```

**ポイント**：一度この「核」を作っておくと、②の企業別資料は差分（志望動機・想定質問・企業との接点・逆質問・志望順位）だけで済むようになる。

## ② 企業別面接対策資料（差分カスタマイズ）

**用途**：①の核を、応募先企業の求人票・企業研究の内容に合わせて調整する

**やり方**
1. 求人票・企業サイト・企業研究の内容を用意する
2. ①の核（志望動機・逆質問）だけをその企業向けに書き換える
3. ファイル名は `YYYY-MM-DD_企業名_面接対策資料.docx` で保存

**プロンプト**
```
以下は転職面接の汎用的な想定問答の核です。この会社の求人内容・企業研究メモに
合わせて、志望動機と逆質問だけをカスタマイズしてください。他の項目（自己紹介、
転職理由、自己PR、実績エピソード）は基本そのまま流用します。

【汎用の核】
（①で作った内容を貼る）

【企業名・求人内容・企業研究メモ】
（ここに貼る）
```

**志望動機の生成ルール**：企業HPの言葉をそのまま並べるのではなく、「自分の経験 × 企業の課題 × 募集ポジション × 今後やりたいこと」の掛け合わせで作る。特に強みとして「人をつなぐ」「事業とITをつなぐ」「知識の断絶を埋める」「課題を整理する」「費用対効果で考える」「現場が自走できる形へ変える」のどれかと企業の課題を接続すると筋が通りやすい。

**ポイント**：志望動機は「経験を活かしたい」で終わらせず、直近の実績を根拠として添え、可能なら現在進行形で取り組んでいること（学習中のスキルなど）も一言添えると厚みが出る。

## ③ エージェント・企業への返信文面

**用途**：選考辞退、日程調整、職務経歴書の更新連絡など、エージェント・企業とのやり取り文面の下書き

**プロンプト**
```
以下の状況を、転職エージェント（または企業）宛ての丁寧なビジネスメールにしてください。

【状況】
（誰に、何を伝えたいか。辞退なら理由も）

【トーン】
・感謝を伝えつつ、結論は明確に
・理由を聞かれている場合は、角が立たない範囲で具体的に書く
```

**ポイント**：選考辞退やポジション変更の断りは、先方から理由を聞かれることが多い。「今後注力したい方向性」など前向きな理由で答えると角が立ちにくい。

## ④ 応募企業一覧（Excel）の更新

**用途**：応募状況の一元管理

**運用ルール**
- 新規応募の追記作業でのGmail確認は、直近24時間分の受信で足りる（過去まで遡って全件確認する必要はない）
- 可視化は通常のグラフではなく、データバー・信号色（進行中/内定/見送り等をセルの色で表現）を使う
- 書類選考落ち・他社決定・内定辞退が確定した企業は、以後の追加リサーチ対象から外す

**採用関連メールの優先度判定**
- 優先して拾う：面接案内、選考結果、日程調整、提出物依頼、内定、オファー、エージェントからの重要連絡
- 無視してよい：広告、プロモーション、メルマガ、SNS通知、サービス通知
- 外部へのメール送信は、AIが勝手に実行しない。必ず「取得 → 優先度判定 → 返信案作成 → ユーザー確認 → 送信」の順を守る（③の返信文面テンプレを下書きに使い、送信は必ずユーザーが行う）

## ⑤ 面接後アンケート（エージェント別フォーマット）

**用途**：面接後にエージェントから求められるアンケート回答の下書き。エージェントによってフォーマットが違うので使い分ける

**リクルートエージェント用**（エン転職とは別フォーマット、2026-09-14固定）：以下6項目、各400字以内
1. 志望度が変化した場合、その理由
2. 担当キャリアアドバイザーにフォローしてほしいこと
3. 企業側に伝えてほしいこと
4. 面接官の印象
5. 魅力と懸念
6. その他、面接で聞かれた質問

**プロンプト**
```
以下の面接内容をもとに、リクルートエージェント宛ての面接後アンケート回答を
6項目（各400字以内）で作成してください。

①志望度が変化した場合、その理由
②担当キャリアアドバイザーにフォローしてほしいこと
③企業側に伝えてほしいこと
④面接官の印象
⑤魅力と懸念
⑥その他、面接で聞かれた質問

【面接の内容・感想メモ】
（ここに貼る）
```

**ポイント**：「魅力と懸念」は両方書くことで、選考継続の温度感を正直かつ前向きに伝えられる。他エージェント（エン転職等）の指定フォーマットが別途あれば、それに合わせて項目・字数を調整する。
